# 연우 체스

태블릿 한 대로 둘이서 두는 체스 게임입니다. `index.html` 파일 하나로 되어 있어서 브라우저로 열면 바로 됩니다.

- 말을 누르면 갈 수 있는 곳이 점으로 보입니다.
- 체크, 체크메이트, 무승부, 캐슬링, 앙파상, 승급까지 정식 규칙을 따릅니다.
- 말을 누르면 그 말이 움직이는 법을 알려 주고, "규칙" 버튼에서 전체 규칙을 볼 수 있습니다.
- 가로로 들어도 항상 세로 화면 배치로 보입니다.
- 무르기, 새 게임, 이름 바꾸기, 소리 켜고 끄기를 지원합니다.
- "마주 보고 앉기"를 켜면 검은 말이 맞은편에 앉은 사람 쪽으로 돌아갑니다.
- 두던 판은 기기에 저장되어 창을 닫았다 열어도 이어집니다.
- 크롬 메뉴에서 "설치"하면 앱처럼 열리고, 세로 화면으로 고정되며, 인터넷 없이도 실행됩니다.
